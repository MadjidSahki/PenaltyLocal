# Penalty 1v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local-network 1v1 penalty shootout game played in the browser, with an authoritative Node server, room codes, UEFA shootout rules, and an original animated visual.

**Architecture:** A Node server using the built-in `http` module to serve static client files and the `ws` library for real-time WebSocket play. The server is authoritative: a pure match-logic module decides goal/save and applies UEFA rules; a room manager pairs two players by code; a connection layer relays secret choices and resolved outcomes. The client is vanilla HTML/CSS/JS with CSS-transform animation.

**Tech Stack:** Node.js, `ws`, built-in `http`; vanilla HTML/CSS/JS client; Node's built-in `node:test` + `node:assert` for tests.

**Spec:** `docs/superpowers/specs/2026-11-02-penalty-1v1-design.md`

## Global Constraints

- Server: Node.js only; dependencies limited to `ws`. Static files served via the built-in `http` module. No web framework.
- Client: vanilla HTML/CSS/JS. No front-end framework. No external art assets; all visuals drawn with CSS/SVG shapes.
- The server is the single source of truth: it validates turns, decides goal/save, tracks score, applies UEFA rules, and tells clients what to render. Clients never decide an outcome.
- Choices are secret: neither player's zone is revealed to the opponent until both the shooter's and keeper's choices for that round are locked in.
- Zones are exactly `"left" | "center" | "right"`. Same zone → save; different → goal.
- Room code: 4 characters from the alphabet `ABCDEFGHJKLMNPQRSTUVWXYZ23456789` (no 0/O/1/I), unique among active rooms.
- A room holds exactly two players; joining a full or nonexistent room is rejected with a clear reason.
- Tests run with `node --test`.

## Review Focus

- **Join a full room:** a third `join` for a room that already has two players must be rejected with a clear reason, not silently accepted or crashing. (Tested in Task 2.)
- **Join a nonexistent/expired code:** `join` with an unknown code must be rejected with a clear reason. (Tested in Task 2.)
- **Invalid or out-of-turn choice:** a choice that isn't one of the three zones, a second choice from a player who already chose this round, or a keeper trying to shoot must be rejected without mutating match state. (Tested in Tasks 1 and 3.)
- **Mid-match disconnect:** if a socket closes during a match, the opponent is notified and the room is cleaned up; no further messages for that room error out. (Tested in Task 3.)
- **Mathematical early finish vs. sudden death boundary:** the match must end the instant the lead is unassailable, and must enter sudden death only on an exact tie after all 5+5 shots — the off-by-one around "5 each" is the likely bug. (Tested in Task 1.)

### Task 1: Pure match-logic module

**Files:**
- Create: `src/match.js`
- Test: `test/match.test.js`

**Interfaces:**
- Produces:
  - `const ZONES = ["left", "center", "right"]`
  - `function createMatch(): MatchState` — fresh match. `MatchState` fields: `scores: {a: number, b: number}`, `shotsTaken: {a: number, b: number}`, `shooter: "a" | "b"` (whose turn to shoot; starts `"a"`), `round: number` (1-based), `phase: "regulation" | "suddenDeath"`, `status: "playing" | "finished"`, `winner: "a" | "b" | null`, `pending: {shooter: Zone | null, keeper: Zone | null}`.
  - `function submitChoice(state: MatchState, player: "a" | "b", zone: Zone): {ok: true, state: MatchState} | {ok: false, reason: string}` — records the choice for whichever role `player` currently holds. Rejects if match finished, zone invalid, or that player already submitted this round. Does **not** resolve until both are in; when both are in, it resolves the round (goal if zones differ, save if equal), updates scores/shots, advances `shooter`/`round`, applies UEFA end/sudden-death rules, and clears `pending`. Returns a new state (pure; never mutates the input).
  - `function roundResult(state: MatchState): RoundResult | null` — after a resolved round, returns `{shooter, keeper, shooterZone, keeperZone, goal: boolean, scores, status, winner}` describing the round just resolved; `null` if the current round isn't resolved yet. (Implementer may instead return the result object directly from `submitChoice`; if so, document it in Interfaces and keep this helper returning the last resolved result.)

```js
const assert = require("node:assert");

test("fresh match: a shoots first, scores zero, playing", () => {
  const m = createMatch();

  assert.equal(m.shooter, "a");
  assert.equal(m.status, "playing");

test("different zones => goal; roles this round: a shoots, b keeps", () => {
  let m = createMatch();
  m = submitChoice(m, "a", "left").state;   // shooter a
  const r = submitChoice(m, "b", "right");  // keeper b
  assert.equal(r.ok, true);
  assert.equal(r.state.scores.a, 1);
  assert.equal(r.state.shooter, "b"); // roles alternate
});

test("same zone => save, no goal", () => {
  let m = createMatch();
  m = submitChoice(m, "a", "center").state;
  const r = submitChoice(m, "b", "center");
  assert.equal(r.state.scores.a, 0);
});

test("invalid zone rejected, state unchanged", () => {
  const m = createMatch();
  const r = submitChoice(m, "a", "up");
  assert.equal(r.ok, false);
  assert.ok(r.reason);
});

test("double submit by same player rejected", () => {
  let m = createMatch();
  m = submitChoice(m, "a", "left").state;
  const r = submitChoice(m, "a", "right");
  assert.equal(r.ok, false);
});

test("choice after match finished rejected", () => {
  // drive a to an unassailable lead, then assert further submit fails
  let m = createMatch();
  // helper: a always shoots left vs b keeper right (goal), b shoots left vs a right (goal)
  const goal = (st, shooter, keeper) =>
    submitChoice(submitChoice(st, shooter, "left").state, keeper, "right").state;
  // a:1 b:0, a:1 b:... build toward 3-0 lead with 2 left each -> unassailable
  m = goal(m, "a", "b"); // a shoots -> 1-0, now b shoots
  m = submitChoice(submitChoice(m, "b", "left").state, "a", "left").state; // b save -> still 1-0, a shoots
  m = goal(m, "a", "b"); // 2-0, b shoots
  m = submitChoice(submitChoice(m, "b", "left").state, "a", "left").state; // save 2-0, a shoots
  m = goal(m, "a", "b"); // 3-0 after a's 3rd; b has 2 shots left, can reach max 2 < 3
  assert.equal(m.status, "finished");
  assert.equal(m.winner, "a");
  const r = submitChoice(m, "b", "left");
  assert.equal(r.ok, false);
});

test("tie after 5 each => sudden death phase", () => {
  let m = createMatch();
  // all saves: a shoots left, b keeps left; then b shoots left, a keeps left; x5 each
  for (let i = 0; i < 10; i++) {
    const shooter = m.shooter;
    const keeper = shooter === "a" ? "b" : "a";
    m = submitChoice(m, shooter, "left").state;
    m = submitChoice(m, keeper, "left").state;
  }
  assert.equal(m.scores.a, 0);
  assert.equal(m.scores.b, 0);
  assert.equal(m.phase, "suddenDeath");
  assert.equal(m.status, "playing");
});
```

### Task 2: Room manager

**Files:**
- Create: `src/rooms.js`
- Test: `test/rooms.test.js`

**Interfaces:**
- Consumes: nothing from other tasks (holds a `MatchState` from Task 1 opaquely as `room.match`, created via a passed-in factory to stay decoupled).
- Produces:
  - `function createRoomManager({ generateCode? }): RoomManager`. `generateCode` is an optional injectable function returning a code string (for deterministic tests); defaults to a random 4-char generator over `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`.
  - `RoomManager.createRoom(player): {code: string, room: Room}` — `player` is `{id, nickname}`. Creates a room with this player as slot `"a"`, a unique code, status `"waiting"`.
  - `RoomManager.joinRoom(code, player): {ok: true, room: Room, slot: "b"} | {ok: false, reason: string}` — rejects unknown code (`"Room not found"`) and full room (`"Room is full"`). On success assigns slot `"b"` and sets room status `"ready"`.
  - `RoomManager.getRoom(code): Room | undefined`.
  - `RoomManager.removeRoom(code): void`.
  - `RoomManager.roomOfPlayer(playerId): Room | undefined`.
  - `Room` shape: `{code, players: {a, b|null}, status: "waiting" | "ready", match: any|null}`.

### Task 3: WebSocket server and protocol

**Files:**
- Create: `src/server.js`
- Create: `package.json`
- Test: `test/server.test.js`

**Interfaces:**
- Consumes: `createMatch`/`submitChoice` from Task 1; `createRoomManager` from Task 2.
- Produces:
  - `function createServer({ port? }): { httpServer, wss, close() }` — starts an `http` server serving `public/` and a `ws` server on the same port. Exported so tests can start it on an ephemeral port and connect real `ws` clients.
  - WebSocket JSON protocol (client → server `type`): `"create"` `{nickname}`, `"join"` `{code, nickname}`, `"choice"` `{zone}`, `"rematch"`.
  - Server → client messages (`type`): `"created"` `{code}`; `"joined"` `{code, you: "a"|"b", opponent: nickname}`; `"error"` `{reason}`; `"start"` `{you, names:{a,b}}`; `"turn"` `{round, shooter, you, role: "shooter"|"keeper"}`; `"waiting"` (your choice accepted, waiting for opponent); `"result"` `{shooterZone, keeperZone, goal, scores, shooter}`; `"matchOver"` `{winner, scores}`; `"opponentLeft"`.
  - The server rejects a `"choice"` that is invalid, out of turn, or a duplicate this round (delegating to `submitChoice`), and never reveals a zone to the opponent before both choices are in.

```js
const test = require("node:test");
const assert = require("node:assert");
const WebSocket = require("ws");
const { createServer } = require("../src/server");

function connect(port) {
  const ws = new WebSocket(`ws://127.0.0.1:${port}`);
  ws.queue = [];
  ws.waiters = [];
  ws.on("message", (d) => {
    const msg = JSON.parse(d);
    const w = ws.waiters.shift();
    if (w) w(msg); else ws.queue.push(msg);
  });
  ws.next = () =>
    new Promise((res) => (ws.queue.length ? res(ws.queue.shift()) : ws.waiters.push(res)));
  ws.send = ((orig) => (obj) => orig.call(ws, JSON.stringify(obj)))(ws.send);
  return new Promise((res) => ws.on("open", () => res(ws)));
}

test("create + join reaches start, then a round resolves to a goal", async () => {
  const srv = createServer({ port: 0 });
  const port = srv.httpServer.address().port;
  const a = await connect(port);
  a.send({ type: "create", nickname: "A" });
  const created = await a.next();
  assert.equal(created.type, "created");
  const b = await connect(port);
  b.send({ type: "join", code: created.code, nickname: "B" });
  // both should receive a start then a turn
  const msgsA = [await a.next(), await a.next()];
  await b.next(); await b.next();
  assert.ok(msgsA.some((m) => m.type === "start"));
  // a is shooter round 1 per logic; both choose different zones => goal
  a.send({ type: "choice", zone: "left" });
  b.send({ type: "choice", zone: "right" });
  // drain until a result arrives for A
  let res = null;
  for (let i = 0; i < 4 && !res; i++) { const m = await a.next(); if (m.type === "result") res = m; }
  assert.ok(res, "a got a result");
  assert.equal(res.goal, true);
  srv.close();
});

test("choice from the keeper's opponent reveals nothing until both in", async () => {
  const srv = createServer({ port: 0 });
  const port = srv.httpServer.address().port;
  const a = await connect(port);
  a.send({ type: "create", nickname: "A" });
  const created = await a.next();
  const b = await connect(port);
  b.send({ type: "join", code: created.code, nickname: "B" });
  await a.next(); await a.next(); await b.next(); await b.next();
  a.send({ type: "choice", zone: "left" });
  const ack = await a.next();
  assert.equal(ack.type, "waiting"); // no result/zone leaked yet
  srv.close();
});

test("join unknown code => error", async () => {
  const srv = createServer({ port: 0 });
  const port = srv.httpServer.address().port;
  const b = await connect(port);
  b.send({ type: "join", code: "ZZZZ", nickname: "B" });
  const m = await b.next();
  assert.equal(m.type, "error");
  srv.close();
});

test("opponent disconnect notifies the other player", async () => {
  const srv = createServer({ port: 0 });
  const port = srv.httpServer.address().port;
  const a = await connect(port);
  a.send({ type: "create", nickname: "A" });
  const created = await a.next();
  const b = await connect(port);
  b.send({ type: "join", code: created.code, nickname: "B" });
  await a.next(); await a.next(); await b.next(); await b.next();
  b.close();
  let left = null;
  for (let i = 0; i < 4 && !left; i++) { const m = await a.next(); if (m.type === "opponentLeft") left = m; }
  assert.ok(left);
  srv.close();
});
```
